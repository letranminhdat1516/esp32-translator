# Phase 4: iPhone Notifications (ANCS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show notifications from the Claude iPhone app on the board (chime, wake even when locked, title / subtitle / message) and let the user trigger the notification's own positive / negative action with an explicit armed tap. The board reads them as an ANCS client on the iPhone's BLE link, without the Mac and, when iOS keeps the link up, without the translator app.

**Architecture:** The board stays the GATT server and peripheral for the translator app. On the same iPhone link it also becomes a GATT client of Apple's Notification Center Service (ANCS). ANCS is only served over an encrypted, bonded link, so `ble_link.c` asks for encryption. iOS then shows a one-time pairing prompt, and later a one-time "receive notifications" prompt. `ancs_client.c` (NimBLE host task) discovers the ANCS service, subscribes to Data Source and then Notification Source, and feeds every event into a pure, host-tested flow (`ancs.c`). For each new notification the flow asks for the App Identifier only. Only when that is exactly the Claude app does it ask for title, subtitle, message and action labels. Nothing from other apps is ever requested beyond the app id, shown, logged or kept. A Claude notice goes to a new screen (`phone_ui.c`), which the shell (`modes.c`) loads over any mode or the lock (a Mac request still wins). Its positive / negative buttons write ANCS `PerformNotificationAction` only on an armed, lit tap.

**Tech Stack:** ESP-IDF 5.5, FreeRTOS, NimBLE (peripheral + GATT client; ESP-IDF compiles the client only with `CONFIG_BT_NIMBLE_ROLE_CENTRAL`), LVGL 9.6 (esp_lvgl_adapter), host C tests compiled with `cc`, the user's iPhone (iOS 26) and the Claude iOS app for the on-device steps.

**Spec:** `docs/superpowers/specs/2026-10-04-board-modes-claude-sessions-design.md`, section "Phase 4: iPhone notifications (ANCS)", plus the decisions agreed in conversation (copied into Global Constraints below; binding). Conventions and the existing protocol: `docs/superpowers/plans/2026-10-04-phase3-voice-commands.md`. Carried from the Phase 3 ledger (`.superpowers/sdd/2026-10-04-phase3-voice-commands/progress.md`): "NimBLE host stack 6144 with headroom ~2.7 KB measured"; "B3 (pre-existing, parked): SPI DMA draw OOM while chime holds codec".

## Global Constraints

- Spec (verbatim): "The board acts as an ANCS client on the iPhone link (encrypted, bonded; one-time pairing prompt on the iPhone)." "Only notifications from the Claude app are shown (filtered by app identifier); chime + text on the board, wake if locked." "If a notification offers positive/negative actions, the board shows them as buttons and performs the action on tap." "Works without the Mac and without the translator app running." "First step of the phase: verify on the user's iPhone which actions Claude app notifications expose."
- Spec (project-wide, verbatim): "Battery is 550 mAh: Claude features must cost nothing while unused." "Nothing is ever auto-approved; every answer comes from an explicit tap" "No unofficial Anthropic APIs, no reading other apps' data on the iPhone, no use of the user's claude.ai credentials." "Deep sleep rules unchanged (battery only, no link for 3 min)."
- Filter (agreed): exact, case-sensitive match of the ANCS App Identifier against `ANCS_CLAUDE_APP_ID` (`ancs.h`). Expected `com.anthropic.claude`; Task 1 confirms it on the user's iPhone and records it in `docs/superpowers/notes/2026-10-05-ancs-discovery.md`. Fetch in two steps: first the App Identifier alone, then title / subtitle / message / labels only for the Claude app. Other apps: no content is requested, shown, logged (after Task 1's probe is removed in Task 4) or kept. The reply buffer is zeroed after every reply.
- Requested sizes (agreed): Title 64, Subtitle 64, Message 240 bytes (ANCS max-length parameters); action labels kept to 32 bytes. Every text goes through `ancs_clean_text`: it drops invalid UTF-8 (the iPhone cuts at a byte count) and characters the board fonts lack (emoji, CJK, …), turns control characters into spaces, folds whitespace and cuts at a character boundary.
- Events (agreed): notifications flagged PreExisting (the dump iOS sends on subscription) are ignored. Silent notifications are shown without a chime. A Modified event for the notice on screen refreshes it without a chime. Removed on the iPhone closes it on the board. A newer Claude notification replaces the one on screen (one notice at a time, nothing stored). At most 8 notifications wait for lookup (a burst drops the oldest). A reply not complete 3 s after its request is given up when the next event arrives (no timer, no polling).
- Display (agreed): screen "iPhone · Claude", title (36 px), subtitle and message (22 px). Close (board only) is always offered. The iPhone's negative / positive actions appear as left (red) / right (green) buttons labelled with the iPhone's own labels ("OK" / "Clear" when a flag comes without a label). The notice closes itself after 20 s, or 60 s when it has action buttons. A tap result ("Done" / "Not done" / "Not sent") stays 1.5 s.
- Screen rules (agreed, `modes.c`): a notice takes the screen over any mode or the lock and wakes the panel. While locked, the panel stays on only while the notice is up and the lock comes back afterwards. A Mac request (`MODES_EV_URGENT`) always wins: it replaces a notice, and a notice arriving during a Mac request is not shown. PWR ×1 with a notice up only closes it (the lock state is unchanged). PWR ×2/×3 and BOOT close it and act as usual. Lock-screen taps and picker picks are ignored while it is up. The mode report to the Mac is unchanged.
- Safety (spec + agreed): an iPhone action is written only from an explicit tap on its button: armed 700 ms after the notice appears, changes or the panel lights (`ARM_DELAY_US`, same as the Claude screen), never from a dark panel, never automatically, and only for the notice on screen (ANCS uid, `ancs_flow_action`). A tap on Close never touches the iPhone.
- Security (agreed): ANCS only over an encrypted link. The board asks for encryption (`ble_gap_security_initiate`): when an unencrypted link subscribes to the translator audio (the translator app; first time = the iOS pairing prompt) and, from Task 6, on connect when the peer is already bonded (silent re-encryption, so ANCS also starts when iOS connects without the app). Pairing stays Just Works with bonding as today.
- GATT table: unchanged in this phase (no new service or characteristic, so `announce_gatt_changes` sends no Service Changed). Advertising gains an ANCS service solicitation in the scan response (Task 6).
- NimBLE: `CONFIG_BT_NIMBLE_ROLE_CENTRAL=y` and `CONFIG_BT_NIMBLE_GATT_CLIENT=y` only to compile the GATT client. The board never scans or initiates connections, so `ROLE_OBSERVER` stays off. Host task stack stays 6144. Every ANCS buffer is static. No large locals in host-task paths (ANCS callbacks keep under ~64 bytes of locals). Data Source reassembly uses the static `ancs_reply_t` inside the static flow. `stack headroom nimble_host` must stay ≥ 2 KB.
- Locks: `s_flow_lock` (ancs_client.c) guards the flow between the host task and the shell / LVGL tasks. Never take the display lock (or call `phone_ui_*`, `chime_play`) while holding `s_flow_lock`. The order is always display lock → flow lock.

## Review Focus

1. **Another app's notification leaks**: a WhatsApp / Messages / Mail notification arrives (alone, in a burst, or interleaved with Claude ones). Expected: the board requests only its App Identifier, shows nothing and keeps nothing; after Task 4 even the app id is not logged. Near-miss ids (`com.anthropic.claude.share`, different case, prefix) are rejected. Tests: Task 2 `other_apps_are_never_fetched_or_kept`; Task 7 row 2.
2. **An action fires on the wrong notification or without intent**: a tap that began before the notice appeared or changed, a tap on a dark panel, a stale uid after the iPhone removed the notification or a newer one replaced it, a tap while the link is gone. Expected: nothing is written to the iPhone. Tests: Task 2 `actions_only_for_the_shown_notice`, `removed_closes_or_drops`, `newer_notice_replaces`; Task 5 on-device rows 3–6.
3. **Data Source replies that are split, foreign or garbled**: a reply split at any byte across notifications, a reply for another uid or command, a reply longer than any we asked for, a value cut mid-UTF-8 by the iPhone, emoji in the title. Expected: reassembled exactly, rejected, or cleaned, never crashing or overrunning. Tests: Task 1 `reply_reassembles_split_chunks`, `reply_rejects_bad_input`, `clean_text_fits_the_fonts`; Task 2 `text_is_cleaned`.
4. **Link and security states**: an unpaired iPhone, pairing declined, the Mac's encrypted link (no ANCS), the Mac and the iPhone encrypting at the same time, reconnecting after a board reset with the app closed (NimBLE restores the bonded iPhone's old audio CCCD). Expected: ANCS on the iPhone link only, nothing breaks for the translator or the Mac, a restored subscription never counts as the translator app, and the user is never asked to pair twice once bonded. Tests: Task 1 on-device rows 1–4, 8–9; Task 6 rows 1–6.
5. **Storms and stalls**: 20 notifications at once, the PreExisting dump on every reconnect, a reply that never completes, a write refused by the iPhone, uid 0. Expected: bounded queue (newest kept), PreExisting ignored, stalled request abandoned after 3 s, the queue keeps moving, uid 0 treated as a real notification. Tests: Task 2 `duplicates_and_overflow`, `preexisting_and_stray_data_are_ignored`, `stalls_and_errors`, `uid_zero_is_a_notification`.

## ANCS wire format (Apple's, both directions; the board implements the client side)

Service `7905F431-B5CE-4E99-A40F-4B1E122D00D0` on the iPhone:

| Characteristic | UUID | Properties | Payload |
|---|---|---|---|
| Notification Source | `9FBF120D-6301-42D9-8C58-25E699A21DBD` | notify | `[event u8][flags u8][category u8][count u8][uid u32 LE]`; event 0 added, 1 modified, 2 removed; flags bit0 silent, bit1 important, bit2 pre-existing, bit3 positive action, bit4 negative action |
| Control Point | `69D1D8F3-45E1-49A8-9821-9BBDFDAAD9D9` | write with response | get notification attributes `[0][uid u32 LE]{[attr id][max u16 LE, Title/Subtitle/Message only]}`; perform action `[2][uid u32 LE][action u8]` (0 positive, 1 negative); ATT errors 0xA0 unknown command, 0xA1 invalid command, 0xA2 invalid parameter, 0xA3 action failed |
| Data Source | `22EAC6E9-24D6-4BB5-BE44-B36ACE7C7BFB` | notify | `[0][uid u32 LE]{[attr id][len u16 LE][UTF-8 value]}` in the requested order, split over as many notifications as needed |

Attribute ids: 0 App Identifier, 1 Title, 2 Subtitle, 3 Message, 6 Positive Action Label, 7 Negative Action Label.

Test vectors (asserted in `test_ancs.c`): app-id request uid `0x01020304` → `00 04 03 02 01 00`; details request uid 42 → `00 2a 00 00 00 01 40 00 02 40 00 03 f0 00 06 07`; positive action uid 42 → `02 2a 00 00 00 00`, negative → `02 2a 00 00 00 01`; Notification Source `00 18 04 01 2a 00 00 00` = added, flags positive + negative, category 4, count 1, uid 42.

```c
// firmware/test/test_ancs.c — build: cc -Wall -Wextra -Werror -I../main -o /tmp/test_ancs test_ancs.c ../main/ancs.c && /tmp/test_ancs
#include <assert.h>
#include <stdio.h>
#include <string.h>
#include "ancs.h"

/* "7905F431-B5CE-..." (big-endian text) → 16 little-endian bytes */
static void uuid_le(const char *s, uint8_t out[16])
{
    uint8_t be[16];
    int n = 0;
    for (const char *p = s; *p && n < 16; p++) {
        if (*p == '-') {
            continue;
        }
        unsigned v;
        assert(sscanf(p, "%2x", &v) == 1);
        be[n++] = (uint8_t)v;
        p++;
    }
    assert(n == 16);
    for (int i = 0; i < 16; i++) {
        out[i] = be[15 - i];
    }
}

static void uuids_match_apple(void)
{
    const uint8_t svc[16] = { ANCS_UUID_SVC }, src[16] = { ANCS_UUID_SOURCE };
    const uint8_t cp[16] = { ANCS_UUID_CONTROL }, ds[16] = { ANCS_UUID_DATA };
    uint8_t want[16];
    uuid_le("7905F431-B5CE-4E99-A40F-4B1E122D00D0", want);
    assert(memcmp(svc, want, 16) == 0);
    uuid_le("9FBF120D-6301-42D9-8C58-25E699A21DBD", want);
    assert(memcmp(src, want, 16) == 0);
    uuid_le("69D1D8F3-45E1-49A8-9821-9BBDFDAAD9D9", want);
    assert(memcmp(cp, want, 16) == 0);
    uuid_le("22EAC6E9-24D6-4BB5-BE44-B36ACE7C7BFB", want);
    assert(memcmp(ds, want, 16) == 0);
}

static void source_parses(void)
{
    const uint8_t d[8] = { 0x00, 0x18, 0x04, 0x01, 0x2a, 0x00, 0x00, 0x00 };
    ancs_source_t ev;
    assert(ancs_parse_source(d, 8, &ev));
    assert(ev.event == ANCS_EVENT_ADDED && ev.flags == (ANCS_FLAG_POSITIVE | ANCS_FLAG_NEGATIVE));
    assert(ev.category == 4 && ev.count == 1 && ev.uid == 42);
    const uint8_t removed[8] = { 0x02, 0x04, 0x00, 0x00, 0x04, 0x03, 0x02, 0x01 };
    assert(ancs_parse_source(removed, 8, &ev) && ev.event == ANCS_EVENT_REMOVED && ev.uid == 0x01020304);
    assert(ev.flags & ANCS_FLAG_PRE_EXISTING);
    assert(!ancs_parse_source(d, 7, &ev));
    const uint8_t nine[9] = { 0 };
    assert(!ancs_parse_source(nine, 9, &ev));
    const uint8_t bad_event[8] = { 0x03, 0, 0, 0, 1, 0, 0, 0 };
    assert(!ancs_parse_source(bad_event, 8, &ev));
}

static void commands_match_apple(void)
{
    uint8_t out[ANCS_CMD_MAX];
    assert(ancs_encode_get_attrs(0x01020304, ANCS_APP_ATTRS, sizeof ANCS_APP_ATTRS, out, sizeof out) == 6);
    const uint8_t want_app[6] = { 0x00, 0x04, 0x03, 0x02, 0x01, 0x00 };
    assert(memcmp(out, want_app, 6) == 0);
    assert(ancs_encode_get_attrs(42, ANCS_DETAIL_ATTRS, sizeof ANCS_DETAIL_ATTRS, out, sizeof out) == 16);
    const uint8_t want_details[16] = { 0x00, 0x2a, 0x00, 0x00, 0x00, 0x01, 0x40, 0x00, 0x02, 0x40, 0x00,
                                       0x03, 0xf0, 0x00, 0x06, 0x07 };
    assert(memcmp(out, want_details, 16) == 0);
    assert(ancs_encode_get_attrs(42, ANCS_DETAIL_ATTRS, sizeof ANCS_DETAIL_ATTRS, out, 15) == 0);   /* too small */
    assert(ancs_encode_get_attrs(42, ANCS_DETAIL_ATTRS, 0, out, sizeof out) == 0);                  /* nothing asked */
    assert(ancs_encode_action(42, ANCS_ACTION_POSITIVE, out) == 6);
    const uint8_t want_pos[6] = { 0x02, 0x2a, 0x00, 0x00, 0x00, 0x00 };
    assert(memcmp(out, want_pos, 6) == 0);
    assert(ancs_encode_action(42, ANCS_ACTION_NEGATIVE, out) == 6 && out[5] == 0x01);
    assert(ancs_encode_action(42, 2, out) == 0);
}

/* Test reply builders: header [0][uid u32 LE], then [id][len u16 LE][value] */
static size_t reply_header(uint8_t *buf, uint32_t uid)
{
    buf[0] = 0x00;
    buf[1] = uid & 0xff;
    buf[2] = (uid >> 8) & 0xff;
    buf[3] = (uid >> 16) & 0xff;
    buf[4] = (uid >> 24) & 0xff;
    return 5;
}

static size_t put_attr(uint8_t *buf, size_t at, uint8_t id, const char *value)
{
    size_t n = strlen(value);
    buf[at] = id;
    buf[at + 1] = n & 0xff;
    buf[at + 2] = (n >> 8) & 0xff;
    memcpy(buf + at + 3, value, n);
    return at + 3 + n;
}

static size_t details_wire(uint8_t *wire, uint32_t uid)
{
    size_t n = reply_header(wire, uid);
    n = put_attr(wire, n, ANCS_ATTR_TITLE, "Claude");
    n = put_attr(wire, n, ANCS_ATTR_SUBTITLE, "");
    n = put_attr(wire, n, ANCS_ATTR_MESSAGE, "Allow Bash: npm test?");
    n = put_attr(wire, n, ANCS_ATTR_POSITIVE, "Allow");
    return put_attr(wire, n, ANCS_ATTR_NEGATIVE, "Deny");
}

static void reply_reassembles_split_chunks(void)
{
    uint8_t wire[200];
    size_t n = details_wire(wire, 42);
    for (size_t split = 1; split < n; split++) {   /* every split point, as two notifications */
        ancs_reply_t r;
        ancs_reply_start(&r, 42, 5);
        assert(ancs_reply_feed(&r, wire, split) == ANCS_REPLY_MORE);
        assert(ancs_reply_feed(&r, wire + split, n - split) == ANCS_REPLY_DONE);
        const uint8_t *v;
        uint16_t len;
        assert(ancs_reply_attr(&r, ANCS_ATTR_MESSAGE, &v, &len) && len == 21);
        assert(memcmp(v, "Allow Bash: npm test?", 21) == 0);
        assert(ancs_reply_attr(&r, ANCS_ATTR_SUBTITLE, &v, &len) && len == 0);
        assert(ancs_reply_attr(&r, ANCS_ATTR_NEGATIVE, &v, &len) && len == 4 && memcmp(v, "Deny", 4) == 0);
        assert(!ancs_reply_attr(&r, ANCS_ATTR_APP_ID, &v, &len));   /* not asked, not there */
    }
    ancs_reply_t r;   /* one byte per notification */
    ancs_reply_start(&r, 42, 5);
    for (size_t i = 0; i + 1 < n; i++) {
        assert(ancs_reply_feed(&r, wire + i, 1) == ANCS_REPLY_MORE);
    }
    assert(ancs_reply_feed(&r, wire + n - 1, 1) == ANCS_REPLY_DONE);
    ancs_reply_clear(&r);
    static const ancs_reply_t zero;
    assert(memcmp(&r, &zero, sizeof zero) == 0);
}

static void reply_rejects_bad_input(void)
{
    uint8_t wire[64];
```

```c
#include "ancs.h"

#include <string.h>

const uint8_t ANCS_APP_ATTRS[1] = { ANCS_ATTR_APP_ID };
const uint8_t ANCS_DETAIL_ATTRS[5] = { ANCS_ATTR_TITLE, ANCS_ATTR_SUBTITLE, ANCS_ATTR_MESSAGE, ANCS_ATTR_POSITIVE,
                                       ANCS_ATTR_NEGATIVE };

static void put_u32(uint8_t *p, uint32_t v)
{
    p[0] = v & 0xff;
    p[1] = (v >> 8) & 0xff;
    p[2] = (v >> 16) & 0xff;
    p[3] = (v >> 24) & 0xff;
}

static uint32_t get_u32(const uint8_t *p)
{
    return (uint32_t)p[0] | (uint32_t)p[1] << 8 | (uint32_t)p[2] << 16 | (uint32_t)p[3] << 24;
}

bool ancs_parse_source(const uint8_t *data, size_t len, ancs_source_t *out)
{
    if (len != 8 || data[0] > ANCS_EVENT_REMOVED) {
        return false;
    }
    out->event = data[0];
    out->flags = data[1];
    out->category = data[2];
    out->count = data[3];
    out->uid = get_u32(data + 4);
    return true;
}

/* Title, Subtitle and Message take a max length parameter; the other attributes do not */
static uint16_t attr_max(uint8_t id)
{
    switch (id) {
    case ANCS_ATTR_TITLE:
        return ANCS_TITLE_MAX;
    case ANCS_ATTR_SUBTITLE:
        return ANCS_SUBTITLE_MAX;
    case ANCS_ATTR_MESSAGE:
        return ANCS_MESSAGE_MAX;
    default:
        return 0;
    }
}

size_t ancs_encode_get_attrs(uint32_t uid, const uint8_t *ids, size_t n, uint8_t *out, size_t out_size)
{
    size_t len = 5;
    for (size_t i = 0; i < n; i++) {
        len += attr_max(ids[i]) ? 3 : 1;
    }
    if (n == 0 || len > out_size) {
        return 0;
    }
    out[0] = ANCS_CMD_GET_NOTIF_ATTRS;
    put_u32(out + 1, uid);
    size_t p = 5;
    for (size_t i = 0; i < n; i++) {
        uint16_t max = attr_max(ids[i]);
        out[p++] = ids[i];
        if (max) {
            out[p++] = max & 0xff;
            out[p++] = max >> 8;
        }
    }
    return p;
}

size_t ancs_encode_action(uint32_t uid, uint8_t action, uint8_t out[6])
{
    if (action > ANCS_ACTION_NEGATIVE) {
        return 0;
    }
    out[0] = ANCS_CMD_PERFORM_ACTION;
    put_u32(out + 1, uid);
    out[5] = action;
    return 6;
}

void ancs_reply_start(ancs_reply_t *r, uint32_t uid, uint8_t want)
{
    memset(r, 0, sizeof(*r));
    r->uid = uid;
    r->want = want;
    r->active = want > 0;
}

void ancs_reply_clear(ancs_reply_t *r)
{
    memset(r, 0, sizeof(*r));
}

/* Number of complete attributes in the buffer */
static int complete_attrs(const ancs_reply_t *r)
{
    size_t p = 5;
    int n = 0;
    while (p + 3 <= r->len) {
        size_t alen = (size_t)r->buf[p + 1] | (size_t)r->buf[p + 2] << 8;
        if (p + 3 + alen > r->len) {
            break;
        }
        p += 3 + alen;
        n++;
    }
    return n;
}

ancs_reply_status_t ancs_reply_feed(ancs_reply_t *r, const uint8_t *chunk, size_t len)
{
    if (!r->active) {
        return ANCS_REPLY_BAD;
    }
    if (len > sizeof(r->buf) - r->len) {
        r->active = false;
        return ANCS_REPLY_BAD;
    }
    memcpy(r->buf + r->len, chunk, len);
    r->len += len;
    if (r->len >= 5 && (r->buf[0] != ANCS_CMD_GET_NOTIF_ATTRS || get_u32(r->buf + 1) != r->uid)) {
        r->active = false;
        return ANCS_REPLY_BAD;
    }
    if (r->len < 5 || complete_attrs(r) < r->want) {
        return ANCS_REPLY_MORE;
    }
    r->active = false;
    return ANCS_REPLY_DONE;
}

bool ancs_reply_attr(const ancs_reply_t *r, uint8_t id, const uint8_t **value, uint16_t *len)
{
    size_t p = 5;
    for (int i = 0; i < r->want && p + 3 <= r->len; i++) {
        uint16_t alen = (uint16_t)(r->buf[p + 1] | r->buf[p + 2] << 8);
        if (p + 3 + alen > r->len) {
            return false;
        }
        if (r->buf[p] == id) {
            *value = r->buf + p + 3;
            *len = alen;
            return true;
        }
        p += 3 + alen;
    }
    return false;
}

/* The code points font_vi_22 / font_vi_36 carry (their -r ranges) */
static bool glyph_ok(uint32_t c)
{
    return (c >= 0x20 && c <= 0x7e) || (c >= 0xa0 && c <= 0xff) || c == 0x102 || c == 0x103 || c == 0x110 ||
           c == 0x111 || c == 0x128 || c == 0x129 || c == 0x168 || c == 0x169 || c == 0x1a0 || c == 0x1a1 ||
           c == 0x1af || c == 0x1b0 || (c >= 0x1ea0 && c <= 0x1ef9) || c == 0x2013 || c == 0x2014 ||
           (c >= 0x2018 && c <= 0x201d) || c == 0x2026;
}

/* One UTF-8 character at s[0..n): its length, or 0 when invalid (bad lead or continuation, truncated, overlong,
 * surrogate, above U+10FFFF) */
static size_t utf8_next(const uint8_t *s, size_t n, uint32_t *cp)
{
    uint8_t b = s[0];
    size_t len;
    uint32_t c, min;
    if (b < 0x80) {
        *cp = b;
        return 1;
    } else if ((b & 0xe0) == 0xc0) {
        len = 2;
        c = b & 0x1f;
        min = 0x80;
    } else if ((b & 0xf0) == 0xe0) {
        len = 3;
        c = b & 0x0f;
        min = 0x800;
    } else if ((b & 0xf8) == 0xf0) {
        len = 4;
        c = b & 0x07;
        min = 0x10000;
    } else {
        return 0;
    }
    if (len > n) {
        return 0;
    }
    for (size_t i = 1; i < len; i++) {
        if ((s[i] & 0xc0) != 0x80) {
            return 0;
        }
        c = (c << 6) | (s[i] & 0x3f);
    }
    if (c < min || c > 0x10ffff || (c >= 0xd800 && c <= 0xdfff)) {
        return 0;
    }
    *cp = c;
    return len;
}

size_t ancs_clean_text(const uint8_t *src, size_t len, char *out, size_t out_size)
{
    if (out_size == 0) {
        return 0;
    }
    size_t o = 0;
    bool space = false;   /* a space is owed before the next kept character */
    size_t i = 0;
    while (i < len) {
        uint32_t c;
        size_t n = utf8_next(src + i, len - i, &c);
        if (n == 0) {
            i++;   /* skip one bad byte */
            continue;
        }
        const uint8_t *ch = src + i;
        i += n;
        if (c <= 0x20 || c == 0x7f || c == 0xa0 || c == 0x2028 || c == 0x2029) {
            space = o > 0;
            continue;
        }
        if (!glyph_ok(c)) {
            continue;
        }
        size_t need = n + (space ? 1 : 0);
        if (o + need > out_size - 1) {
            break;
        }
        if (space) {
            out[o++] = ' ';
        }
        memcpy(out + o, ch, n);
        o += n;
        space = false;
    }
    out[o] = '\0';
    return o;
}
```

```c
static const char *TAG = "ancs";

static const ble_uuid128_t s_svc_uuid = BLE_UUID128_INIT(ANCS_UUID_SVC);
static const ble_uuid128_t s_source_uuid = BLE_UUID128_INIT(ANCS_UUID_SOURCE);
static const ble_uuid128_t s_control_uuid = BLE_UUID128_INIT(ANCS_UUID_CONTROL);
static const ble_uuid128_t s_data_uuid = BLE_UUID128_INIT(ANCS_UUID_DATA);

/* ---- discovery ---- */

typedef enum { LINK_NONE = 0, LINK_DISCOVERING, LINK_READY } link_state_t;

static struct {
    uint16_t conn;                  /* the link being discovered or ready */
    link_state_t state;
    uint16_t svc_start, svc_end;
    uint16_t source_val, control_val, data_val;
    uint16_t source_end, data_end;  /* last handle of each characteristic (its descriptors end there) */
    uint16_t *open_end;             /* end of the characteristic found last, set when the next one arrives */
    uint16_t source_cccd, data_cccd;
} s_link = { .conn = BLE_HS_CONN_HANDLE_NONE };

/* An encrypted link that came up while another one was being discovered (the Mac and the iPhone together) */
static uint16_t s_waiting_conn = BLE_HS_CONN_HANDLE_NONE;
/* A link already found without ANCS (the Mac): not discovered again until it disconnects */
static uint16_t s_no_ancs_conn = BLE_HS_CONN_HANDLE_NONE;

#define DATA_SOURCE ((void *)1)   /* GATT callback arg: the Data Source step (NULL: Notification Source) */

static void notifications_ready(uint16_t conn);   /* "notifications" section below */
static void start_discovery(uint16_t conn);

static void link_reset(void)
{
    memset(&s_link, 0, sizeof(s_link));
    s_link.conn = BLE_HS_CONN_HANDLE_NONE;
}

static void next_discovery(void)
{
    uint16_t next = s_waiting_conn;
    s_waiting_conn = BLE_HS_CONN_HANDLE_NONE;
    if (next != BLE_HS_CONN_HANDLE_NONE) {
        start_discovery(next);
    }
}

static void give_up(const char *why)
{
    ESP_LOGI(TAG, "link %d: %s", s_link.conn, why);
    s_no_ancs_conn = s_link.conn;
    link_reset();
    next_discovery();
}

static int on_cccd_written(uint16_t conn, const struct ble_gatt_error *error, struct ble_gatt_attr *attr, void *arg);

static void subscribe(uint16_t cccd, void *arg)
{
    static const uint8_t notify_on[2] = { 0x01, 0x00 };
    int rc = ble_gattc_write_flat(s_link.conn, cccd, notify_on, sizeof(notify_on), on_cccd_written, arg);
    if (rc != 0) {
        ESP_LOGW(TAG, "subscription write not started: rc %d", rc);
        give_up("iPhone notifications not subscribed");
    }
}

static int on_cccd_written(uint16_t conn, const struct ble_gatt_error *error, struct ble_gatt_attr *attr, void *arg)
{
    if (conn != s_link.conn || s_link.state != LINK_DISCOVERING) {
        return 0;
    }
    bool data = arg == DATA_SOURCE;
    if (error->status != 0) {
        ESP_LOGW(TAG, "%s subscription refused: status 0x%x", data ? "Data Source" : "Notification Source",
                 error->status);
        give_up("iPhone notifications not available on this link");
        return 0;
    }
    if (data) {
        subscribe(s_link.source_cccd, NULL);
        return 0;
    }
    s_link.state = LINK_READY;
    s_waiting_conn = BLE_HS_CONN_HANDLE_NONE;   /* one ANCS link */
    notifications_ready(conn);
    return 0;
}

static int on_dsc(uint16_t conn, const struct ble_gatt_error *error, uint16_t chr_val_handle,
                  const struct ble_gatt_dsc *dsc, void *arg);

static void find_cccd(uint16_t val, uint16_t end, void *arg)
{
    if (end <= val) {
        give_up("ANCS characteristic without a CCCD");
        return;
    }
    if (ble_gattc_disc_all_dscs(s_link.conn, val, end, on_dsc, arg) != 0) {
        give_up("descriptor discovery not started");
    }
}

static int on_dsc(uint16_t conn, const struct ble_gatt_error *error, uint16_t chr_val_handle,
                  const struct ble_gatt_dsc *dsc, void *arg)
{
    if (conn != s_link.conn || s_link.state != LINK_DISCOVERING) {
        return 0;
    }
    bool data = arg == DATA_SOURCE;
    if (error->status == 0) {
        if (ble_uuid_cmp(&dsc->uuid.u, BLE_UUID16_DECLARE(BLE_GATT_DSC_CLT_CFG_UUID16)) == 0) {
            if (data) {
                s_link.data_cccd = dsc->handle;
            } else {
                s_link.source_cccd = dsc->handle;
            }
        }
        return 0;
    }
    if (error->status != BLE_HS_EDONE) {
        give_up("descriptor discovery failed");
    } else if (data) {
        find_cccd(s_link.source_val, s_link.source_end, NULL);
    } else if (s_link.data_cccd == 0 || s_link.source_cccd == 0) {
        give_up("ANCS CCCDs missing");
    } else {
        subscribe(s_link.data_cccd, DATA_SOURCE);   /* Data Source first: no attribute reply can be missed */
    }
    return 0;
}

static int on_chr(uint16_t conn, const struct ble_gatt_error *error, const struct ble_gatt_chr *chr, void *arg)
{
    if (conn != s_link.conn || s_link.state != LINK_DISCOVERING) {
        return 0;
    }
    if (error->status == 0) {
        if (s_link.open_end) {
            *s_link.open_end = chr->def_handle - 1;
            s_link.open_end = NULL;
        }
        if (ble_uuid_cmp(&chr->uuid.u, &s_source_uuid.u) == 0) {
            s_link.source_val = chr->val_handle;
            s_link.open_end = &s_link.source_end;
        } else if (ble_uuid_cmp(&chr->uuid.u, &s_control_uuid.u) == 0) {
            s_link.control_val = chr->val_handle;
        } else if (ble_uuid_cmp(&chr->uuid.u, &s_data_uuid.u) == 0) {
            s_link.data_val = chr->val_handle;
            s_link.open_end = &s_link.data_end;
        }
        return 0;
    }
    if (s_link.open_end) {
        *s_link.open_end = s_link.svc_end;
        s_link.open_end = NULL;
    }
    if (error->status != BLE_HS_EDONE || !s_link.source_val || !s_link.control_val || !s_link.data_val) {
        give_up("ANCS characteristics missing");
        return 0;
    }
    find_cccd(s_link.data_val, s_link.data_end, DATA_SOURCE);
    return 0;
}

static int on_svc(uint16_t conn, const struct ble_gatt_error *error, const struct ble_gatt_svc *svc, void *arg)
{
    if (conn != s_link.conn || s_link.state != LINK_DISCOVERING) {
        return 0;
    }
    if (error->status == 0) {
        s_link.svc_start = svc->start_handle;
        s_link.svc_end = svc->end_handle;
        return 0;
    }
    if (error->status != BLE_HS_EDONE || s_link.svc_start == 0) {
        give_up("no iPhone notification service (not an iPhone, or not shared)");
        return 0;
    }
    ESP_LOGI(TAG, "link %d: ANCS at 0x%04x..0x%04x", conn, s_link.svc_start, s_link.svc_end);
    if (ble_gattc_disc_all_chrs(conn, s_link.svc_start, s_link.svc_end, on_chr, NULL) != 0) {
        give_up("characteristic discovery not started");
    }
    return 0;
}

static void start_discovery(uint16_t conn)
{
    link_reset();
    s_link.conn = conn;
    s_link.state = LINK_DISCOVERING;
    if (ble_gattc_disc_svc_by_uuid(conn, &s_svc_uuid.u, on_svc, NULL) != 0) {
        give_up("service discovery not started");
    }
}

void ancs_client_on_encrypted(uint16_t conn)
{
    if (conn == s_link.conn || conn == s_no_ancs_conn) {
        return;   /* re-encryption of a link already handled */
    }
    if (s_link.state == LINK_READY) {
        return;   /* one ANCS link */
    }
    if (s_link.state == LINK_DISCOVERING) {
        s_waiting_conn = conn;
        return;
    }
    start_discovery(conn);
}

/* Disconnect bookkeeping. True when conn carried the ready ANCS link. */
static bool link_forget(uint16_t conn)
{
    if (conn == s_waiting_conn) {
        s_waiting_conn = BLE_HS_CONN_HANDLE_NONE;
    }
    if (conn == s_no_ancs_conn) {
        s_no_ancs_conn = BLE_HS_CONN_HANDLE_NONE;
    }
    if (conn != s_link.conn) {
        return false;
    }
    bool ready = s_link.state == LINK_READY;
    link_reset();
    next_discovery();
    return ready;
}

/* ---- notifications ---- */
/* Task 1 discovery probe: logs every notification's app id, and the details of notifications whose app id
 * contains "claude" or "anthropic". Replaced by the notice flow (ancs.c) in Task 4. */

#define PROBE_QUEUE 8
static uint32_t s_probe_queue[PROBE_QUEUE];
static uint8_t s_probe_flags[PROBE_QUEUE];
static int s_probe_n;
static int s_probe_step;   /* 0 idle, 1 app id asked, 2 details asked */
static uint32_t s_probe_uid;
static uint8_t s_probe_uid_flags;
static ancs_reply_t s_probe_reply;
static char s_probe_text[ANCS_MESSAGE_MAX + 1];

static void probe_next(void);

static int on_probe_written(uint16_t conn, const struct ble_gatt_error *error, struct ble_gatt_attr *attr, void *arg)
{
    if (error->status != 0) {
        ESP_LOGW(TAG, "probe: request for %lu refused, status 0x%x", (unsigned long)s_probe_uid, error->status);
        s_probe_step = 0;
        probe_next();
    }
    return 0;
}

static void probe_ask(uint32_t uid, int step)
{
    uint8_t cmd[ANCS_CMD_MAX];
    const uint8_t *ids = step == 1 ? ANCS_APP_ATTRS : ANCS_DETAIL_ATTRS;
    size_t n = step == 1 ? sizeof ANCS_APP_ATTRS : sizeof ANCS_DETAIL_ATTRS;
    size_t len = ancs_encode_get_attrs(uid, ids, n, cmd, sizeof cmd);
    ancs_reply_start(&s_probe_reply, uid, (uint8_t)n);
    s_probe_uid = uid;
    s_probe_step = step;
    int rc = ble_gattc_write_flat(s_link.conn, s_link.control_val, cmd, len, on_probe_written, NULL);
    if (rc != 0) {
        ESP_LOGW(TAG, "probe: write not started, rc %d", rc);
        s_probe_step = 0;
    }
}

static void probe_next(void)
{
    if (s_probe_step != 0 || s_probe_n == 0) {
        return;
    }
    uint32_t uid = s_probe_queue[0];
    s_probe_uid_flags = s_probe_flags[0];
    s_probe_n--;
    memmove(s_probe_queue, s_probe_queue + 1, s_probe_n * sizeof s_probe_queue[0]);
    memmove(s_probe_flags, s_probe_flags + 1, s_probe_n);
    probe_ask(uid, 1);
}

static bool contains_ci(const char *s, const char *word)   /* word in lower case */
{
    size_t n = strlen(word);
    for (; *s; s++) {
        size_t i = 0;
        while (i < n && s[i] && (s[i] | 0x20) == word[i]) {
            i++;
        }
        if (i == n) {
            return true;
        }
    }
    return false;
}

static void probe_log_attr(const char *name, uint8_t id)
{
    const uint8_t *v;
    uint16_t len;
    if (!ancs_reply_attr(&s_probe_reply, id, &v, &len)) {
        ESP_LOGI(TAG, "  %s: (missing)", name);
        return;
    }
    ancs_clean_text(v, len, s_probe_text, sizeof s_probe_text);
    ESP_LOGI(TAG, "  %s (%u bytes): \"%s\"", name, len, s_probe_text);
}

static void probe_on_source(const ancs_source_t *ev)
{
    ESP_LOGI(TAG, "source: event %u flags 0x%02x category %u count %u uid %lu", ev->event, ev->flags, ev->category,
             ev->count, (unsigned long)ev->uid);
    if (ev->event == ANCS_EVENT_REMOVED || (ev->flags & ANCS_FLAG_PRE_EXISTING) || s_probe_n == PROBE_QUEUE) {
        return;
    }
    s_probe_queue[s_probe_n] = ev->uid;
    s_probe_flags[s_probe_n++] = ev->flags;
    probe_next();
}

static void probe_on_data(const uint8_t *data, uint16_t len)
{
    if (s_probe_step == 0) {
        ESP_LOGW(TAG, "probe: %u stray Data Source bytes", len);
        return;
    }
    ancs_reply_status_t st = ancs_reply_feed(&s_probe_reply, data, len);
    if (st == ANCS_REPLY_MORE) {
        return;
    }
    int step = s_probe_step;
    s_probe_step = 0;
    if (st == ANCS_REPLY_BAD) {
        ESP_LOGW(TAG, "probe: bad reply for %lu", (unsigned long)s_probe_uid);
    } else if (step == 1) {
        const uint8_t *v;
        uint16_t n;
        s_probe_text[0] = '\0';
        if (ancs_reply_attr(&s_probe_reply, ANCS_ATTR_APP_ID, &v, &n)) {
            ancs_clean_text(v, n, s_probe_text, sizeof s_probe_text);
        }
        ESP_LOGI(TAG, "uid %lu app \"%s\"", (unsigned long)s_probe_uid, s_probe_text);
        if (contains_ci(s_probe_text, "claude") || contains_ci(s_probe_text, "anthropic")) {
            probe_ask(s_probe_uid, 2);
            return;
        }
    } else {
        ESP_LOGI(TAG, "uid %lu details (flags 0x%02x, positive action %s, negative action %s):",
                 (unsigned long)s_probe_uid, s_probe_uid_flags, (s_probe_uid_flags & ANCS_FLAG_POSITIVE) ? "yes" : "no",
                 (s_probe_uid_flags & ANCS_FLAG_NEGATIVE) ? "yes" : "no");
        probe_log_attr("title", ANCS_ATTR_TITLE);
        probe_log_attr("subtitle", ANCS_ATTR_SUBTITLE);
        probe_log_attr("message", ANCS_ATTR_MESSAGE);
        probe_log_attr("positive label", ANCS_ATTR_POSITIVE);
        probe_log_attr("negative label", ANCS_ATTR_NEGATIVE);
    }
    ancs_reply_clear(&s_probe_reply);
    probe_next();
}

static void notifications_ready(uint16_t conn)
{
    s_probe_n = 0;
    s_probe_step = 0;
    ESP_LOGI(TAG, "link %d: iPhone notifications on (discovery probe)", conn);
}

bool ancs_client_on_notify(uint16_t conn, uint16_t attr, const uint8_t *data, uint16_t len)
{
    if (conn != s_link.conn || s_link.state != LINK_READY) {
        return false;
    }
    if (attr == s_link.source_val) {
        ancs_source_t ev;
        if (ancs_parse_source(data, len, &ev)) {
            probe_on_source(&ev);
        } else {
            ESP_LOGW(TAG, "probe: Notification Source of %u bytes", len);
        }
        return true;
    }
    if (attr == s_link.data_val) {
        probe_on_data(data, len);
        return true;
    }
    return false;
}

void ancs_client_on_disconnect(uint16_t conn)
{
    if (link_forget(conn)) {
        s_probe_n = 0;
        s_probe_step = 0;
        ancs_reply_clear(&s_probe_reply);
        ESP_LOGI(TAG, "iPhone notifications off");
    }
}
```

```c
{
    uint8_t wire[128];
    size_t n = reply_header(wire, uid);
    n = put_attr(wire, n, ANCS_ATTR_APP_ID, app);
    return ancs_flow_on_data(f, wire, n);
}

/* A details reply in two notifications, as the iPhone splits at the MTU */
static ancs_out_t details_reply(ancs_flow_t *f, uint32_t uid, const char *title, const char *message,
                                const char *positive, const char *negative)
{
    uint8_t wire[512];
    size_t n = reply_header(wire, uid);
    n = put_attr(wire, n, ANCS_ATTR_TITLE, title);
    n = put_attr(wire, n, ANCS_ATTR_SUBTITLE, "");
    n = put_attr(wire, n, ANCS_ATTR_MESSAGE, message);
    n = put_attr(wire, n, ANCS_ATTR_POSITIVE, positive);
    n = put_attr(wire, n, ANCS_ATTR_NEGATIVE, negative);
    assert(ancs_flow_on_data(f, wire, n / 2) == ANCS_OUT_NONE);
    return ancs_flow_on_data(f, wire + n / 2, n - n / 2);
}

/* Takes a Claude notification through both lookups; returns the details result */
static ancs_out_t show(ancs_flow_t *f, uint32_t uid, uint8_t flags)
{
    uint8_t cmd[ANCS_CMD_MAX];
    assert(source(f, ANCS_EVENT_ADDED, flags, uid) == ANCS_OUT_NONE);
    assert(ancs_flow_next(f, 0, cmd) == 6 && cmd[5] == ANCS_ATTR_APP_ID);
    assert(app_reply(f, uid, ANCS_CLAUDE_APP_ID) == ANCS_OUT_NONE);
    assert(ancs_flow_next(f, 0, cmd) == 16);

}
```

```c
/* ---- notice flow (Task 2) ----
 * Every Notification Source event goes to ancs_flow_on_source(). ancs_flow_next() says which Control Point
 * command to write (one outstanding at a time): first the App Identifier alone; only for ANCS_CLAUDE_APP_ID
 * the details (title, subtitle, message, action labels). Data Source bytes go to ancs_flow_on_data(). The
 * board holds at most one notice (the one on screen); nothing from other apps is asked beyond the app id, and
 * every reply is zeroed once read. Pre-existing notifications (the dump at subscription) are ignored. A reply
 * missing for ANCS_REPLY_TIMEOUT_MS is given up at the next ancs_flow_next() (no timer). */
#define ANCS_QUEUE_MAX        8
#define ANCS_REPLY_TIMEOUT_MS 3000

typedef struct {
    uint32_t uid;
    uint8_t flags;                           /* ANCS_FLAG_* of the latest event */
    char title[ANCS_TITLE_MAX + 1];
    char subtitle[ANCS_SUBTITLE_MAX + 1];
    char message[ANCS_MESSAGE_MAX + 1];
    char positive[ANCS_LABEL_MAX + 1];       /* "" = no positive action */
    char negative[ANCS_LABEL_MAX + 1];       /* "" = no negative action */
} ancs_notice_t;

typedef enum { ANCS_STEP_IDLE = 0, ANCS_STEP_APP, ANCS_STEP_DETAILS } ancs_step_t;

typedef struct {
    uint32_t uid;
    uint8_t flags;
    ancs_step_t step;                        /* APP: look up the app id; DETAILS: a known Claude notification */
} ancs_queued_t;

typedef struct {
    ancs_queued_t queue[ANCS_QUEUE_MAX];
    int nq;
    ancs_step_t step;                        /* the command outstanding; IDLE = none */
    uint32_t uid;                            /* its notification */
    uint8_t flags;
    bool dropped;                            /* removed on the iPhone meanwhile: its reply is thrown away */
    uint32_t sent_ms;
    ancs_reply_t reply;
    bool shown;                              /* notice holds the notification on the board */
    ancs_notice_t notice;
} ancs_flow_t;

typedef enum {
    ANCS_OUT_NONE = 0,
    ANCS_OUT_SHOW,     /* a new Claude notice (chime unless ANCS_FLAG_SILENT) */
    ANCS_OUT_UPDATE,   /* the notice on screen changed (no chime) */
    ANCS_OUT_GONE,     /* the notice on screen was removed on the iPhone */
} ancs_out_t;

bool ancs_app_allowed(const uint8_t *id, size_t len);   /* exactly ANCS_CLAUDE_APP_ID */
void ancs_flow_init(ancs_flow_t *f);                    /* also on every (re)subscription and disconnect */
ancs_out_t ancs_flow_on_source(ancs_flow_t *f, const ancs_source_t *ev);
size_t ancs_flow_next(ancs_flow_t *f, uint32_t now_ms, uint8_t out[ANCS_CMD_MAX]);
ancs_out_t ancs_flow_on_data(ancs_flow_t *f, const uint8_t *chunk, size_t len);
void ancs_flow_on_error(ancs_flow_t *f);                /* the outstanding command was refused or not sent */
/* Perform Notification Action bytes for the notice on screen only (uid matches, that action offered); else 0 */
size_t ancs_flow_action(const ancs_flow_t *f, uint32_t uid, uint8_t action, uint8_t out[6]);
void ancs_flow_close(ancs_flow_t *f, uint32_t uid);     /* the board closed that notice: forget it */
```

Append to `firmware/main/ancs.c`:

```c
/* ---- notice flow ---- */

bool ancs_app_allowed(const uint8_t *id, size_t len)
{
    static const char claude[] = ANCS_CLAUDE_APP_ID;
    return len == sizeof(claude) - 1 && memcmp(id, claude, len) == 0;
}

void ancs_flow_init(ancs_flow_t *f)
{
    memset(f, 0, sizeof(*f));
}

static int find_queued(const ancs_flow_t *f, uint32_t uid)
{
    for (int i = 0; i < f->nq; i++) {
        if (f->queue[i].uid == uid) {
            return i;
        }
    }
    return -1;
}

static void unqueue(ancs_flow_t *f, int i)
{
    memmove(&f->queue[i], &f->queue[i + 1], (size_t)(f->nq - i - 1) * sizeof f->queue[0]);
    f->nq--;
}

/* Queues uid (front: the details of a Claude notification go next). Already queued: updates it. Full: the
 * oldest waits no longer. */
static void enqueue(ancs_flow_t *f, uint32_t uid, uint8_t flags, ancs_step_t step, bool front)
{
    int i = find_queued(f, uid);
    if (i >= 0) {
        f->queue[i].flags = flags;
        if (step == ANCS_STEP_DETAILS) {
            f->queue[i].step = step;
        }
        return;
    }
    if (f->nq == ANCS_QUEUE_MAX) {
        unqueue(f, 0);
    }
    if (front) {
        memmove(&f->queue[1], &f->queue[0], (size_t)f->nq * sizeof f->queue[0]);
        i = 0;
    } else {
        i = f->nq;
    }
    f->queue[i] = (ancs_queued_t){ .uid = uid, .flags = flags, .step = step };
    f->nq++;
}

ancs_out_t ancs_flow_on_source(ancs_flow_t *f, const ancs_source_t *ev)
{
    bool on_board = f->shown && f->notice.uid == ev->uid;
    bool in_flight = f->step != ANCS_STEP_IDLE && f->uid == ev->uid;
    if (ev->event == ANCS_EVENT_REMOVED) {
        int i = find_queued(f, ev->uid);
        if (i >= 0) {
            unqueue(f, i);
        }
        if (in_flight) {
            f->dropped = true;
        }
        if (on_board) {
            f->shown = false;
            memset(&f->notice, 0, sizeof f->notice);
            return ANCS_OUT_GONE;
        }
        return ANCS_OUT_NONE;
    }
    if (ev->flags & ANCS_FLAG_PRE_EXISTING) {
        return ANCS_OUT_NONE;   /* the dump iOS sends on subscription: old news */
    }
    if (in_flight) {
        f->flags = ev->flags;
        return ANCS_OUT_NONE;
    }
    bool refresh = ev->event == ANCS_EVENT_MODIFIED && on_board;
    enqueue(f, ev->uid, ev->flags, refresh ? ANCS_STEP_DETAILS : ANCS_STEP_APP, false);
    return ANCS_OUT_NONE;
}

size_t ancs_flow_next(ancs_flow_t *f, uint32_t now_ms, uint8_t out[ANCS_CMD_MAX])
{
    if (f->step != ANCS_STEP_IDLE) {
        if ((uint32_t)(now_ms - f->sent_ms) < ANCS_REPLY_TIMEOUT_MS) {
            return 0;
        }
        f->step = ANCS_STEP_IDLE;   /* no complete reply in time: give up on that one */
        ancs_reply_clear(&f->reply);
    }
    if (f->nq == 0) {
        return 0;
    }
    ancs_queued_t q = f->queue[0];
    unqueue(f, 0);
    f->uid = q.uid;
    f->flags = q.flags;
    f->step = q.step;
    f->dropped = false;
    f->sent_ms = now_ms;
    bool app = q.step == ANCS_STEP_APP;
    const uint8_t *ids = app ? ANCS_APP_ATTRS : ANCS_DETAIL_ATTRS;
    size_t n = app ? sizeof ANCS_APP_ATTRS : sizeof ANCS_DETAIL_ATTRS;
    ancs_reply_start(&f->reply, q.uid, (uint8_t)n);
    return ancs_encode_get_attrs(q.uid, ids, n, out, ANCS_CMD_MAX);
}

/* Attribute id of the finished reply, cleaned for the fonts; "" when missing */
static void take_text(const ancs_reply_t *r, uint8_t id, char *out, size_t size)
{
    const uint8_t *v;
    uint16_t len;
    if (ancs_reply_attr(r, id, &v, &len)) {
        ancs_clean_text(v, len, out, size);
    } else {
        out[0] = '\0';
    }
}

ancs_out_t ancs_flow_on_data(ancs_flow_t *f, const uint8_t *chunk, size_t len)
{
    if (f->step == ANCS_STEP_IDLE) {
        return ANCS_OUT_NONE;   /* nothing asked: a stray or late reply */
    }
    ancs_reply_status_t st = ancs_reply_feed(&f->reply, chunk, len);
    if (st == ANCS_REPLY_MORE) {
        return ANCS_OUT_NONE;
    }
    ancs_step_t step = f->step;
    f->step = ANCS_STEP_IDLE;
    ancs_out_t out = ANCS_OUT_NONE;
    if (st == ANCS_REPLY_DONE && !f->dropped) {
        if (step == ANCS_STEP_APP) {
            const uint8_t *v;
            uint16_t n;
            if (ancs_reply_attr(&f->reply, ANCS_ATTR_APP_ID, &v, &n) && ancs_app_allowed(v, n)) {
                enqueue(f, f->uid, f->flags, ANCS_STEP_DETAILS, true);
            }
        } else {
            bool same = f->shown && f->notice.uid == f->uid;
            ancs_notice_t *n = &f->notice;
            memset(n, 0, sizeof *n);
            n->uid = f->uid;
            n->flags = f->flags;
            take_text(&f->reply, ANCS_ATTR_TITLE, n->title, sizeof n->title);
            take_text(&f->reply, ANCS_ATTR_SUBTITLE, n->subtitle, sizeof n->subtitle);
            take_text(&f->reply, ANCS_ATTR_MESSAGE, n->message, sizeof n->message);
            if (f->flags & ANCS_FLAG_POSITIVE) {
                take_text(&f->reply, ANCS_ATTR_POSITIVE, n->positive, sizeof n->positive);
                if (n->positive[0] == '\0') {
                    strcpy(n->positive, "OK");
                }
            }
            if (f->flags & ANCS_FLAG_NEGATIVE) {
                take_text(&f->reply, ANCS_ATTR_NEGATIVE, n->negative, sizeof n->negative);
                if (n->negative[0] == '\0') {
                    strcpy(n->negative, "Clear");
                }
            }
            f->shown = true;
            out = same ? ANCS_OUT_UPDATE : ANCS_OUT_SHOW;
        }
    }
    ancs_reply_clear(&f->reply);
    return out;
}

void ancs_flow_on_error(ancs_flow_t *f)
{
    f->step = ANCS_STEP_IDLE;
    ancs_reply_clear(&f->reply);
}

size_t ancs_flow_action(const ancs_flow_t *f, uint32_t uid, uint8_t action, uint8_t out[6])
{
    const char *label = action == ANCS_ACTION_POSITIVE   ? f->notice.positive
                        : action == ANCS_ACTION_NEGATIVE ? f->notice.negative
                                                         : "";
    if (!f->shown || f->notice.uid != uid || label[0] == '\0') {
        return 0;
    }
    return ancs_encode_action(uid, action, out);
}

        f->shown = false;
        memset(&f->notice, 0, sizeof f->notice);
    }
}
```

```c
static void pump(void)

        uint8_t cmd[ANCS_CMD_MAX];
        flow_lock();

bool ancs_client_on_notify(uint16_t conn, uint16_t attr, const uint8_t *data, uint16_t len)
{
    if (conn != s_link.conn || s_link.state != LINK_READY) {
        return false;
    }
    ancs_out_t out = ANCS_OUT_NONE;
    uint32_t uid = 0;
    if (attr == s_link.source_val) {
        ancs_source_t ev;
        if (!ancs_parse_source(data, len, &ev)) {
            return true;
        }
        uid = ev.uid;
        flow_lock();
        out = ancs_flow_on_source(&s_flow, &ev);
        flow_unlock();
    } else if (attr == s_link.data_val) {
        flow_lock();
        out = ancs_flow_on_data(&s_flow, data, len);
        if (out == ANCS_OUT_SHOW || out == ANCS_OUT_UPDATE) {
            s_snapshot = s_flow.notice;
        }
        flow_unlock();
    } else {
        return false;
    }
    deliver(out, uid);
    pump();
    return true;
}
```
