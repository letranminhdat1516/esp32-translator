# Phase 1: Board Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the board four modes (Translator, Claude, Session picker, Locked) driven by PWR ×1/×2/×3, BOOT ×1 and lock-screen taps, with a battery-frugal lock face (animated pixel cat, clock set over BLE by the iPhone and the Mac, battery %).

**Architecture:** A pure-C state machine (`modes.c`, host-tested) owns modes, the lock, the 5 s lock face and Claude "urgent" takeovers, and also counts PWR presses. A small `shell.c` task feeds it events from every source (PMU poll, BOOT interrupt, LVGL tap callbacks, Claude messages) through a non-blocking queue and applies the result (which LVGL screen is loaded, panel wake). `ui.c`'s existing 250 ms screen timer reads a snapshot of the state to decide panel power and to show or hide the lock face. Time arrives as one ASCII message `"<unix seconds> <UTC offset minutes>"` on the translator text characteristic (iPhone) or as a new Claude message kind (Mac), and is kept with `settimeofday`.

**Tech Stack:** ESP-IDF 5.5, FreeRTOS, LVGL 9.6 (esp_lvgl_adapter), NimBLE; host C tests compiled with `cc`; Python 3 (standard library only) for the pixel-art generator; Swift 6 package with Swift Testing (Mac daemon); SwiftUI/CoreBluetooth iOS app.

**Spec:** `docs/superpowers/specs/2026-10-04-board-modes-claude-sessions-design.md` (section "Phase 1: board shell (buttons, lock screen, modes)")

## Global Constraints

- Inputs, verbatim from the spec table (Unlocked | Locked):
  - PWR ×1: Lock | Unlock (to the mode in use before locking)
  - PWR ×2: Claude mode | Unlock → Claude mode
  - PWR ×3: Session picker | Unlock → Session picker
  - PWR hold 3 s: Power off (battery) / screen off (USB) — unchanged | same
  - BOOT ×1: Translator mode | Unlock → Translator mode
  - Tap ×1 on screen: normal UI | Show the lock face for 5 s: animated pixel cat, clock, battery %
  - Tap ×2 on screen: (Translator: toggles screen off as today) | Unlock
- Locked = panel off and touch inert except the two lock gestures; BLE links, translation and Claude notifications keep running. An important Claude event (in Phase 1: a permission request) wakes the panel and shows it; the user still answers with taps (the 700 ms arming delay applies).
- Battery % moves from PWR ×1 to the lock face.
- Clock: the iPhone (translator link) and the Mac (Claude link) send the current time (UTC + offset) on connect; the board keeps time with its RTC timer. If no time is known yet, the face shows `--:--`.
- Time wire format (both senders): ASCII `"<unix seconds> <UTC offset minutes>"`, decimal, offset may be signed, e.g. `"1759555200 420"`, `"1759555200 -330"`. iPhone: one write **with response** on the text characteristic `A7C00003-…`: `[0x03 flags first|last][0x02 kind time][ASCII]`. Mac: Claude request kind 3, id 0: `[0x03][0x00 0x00 0x00 0x00][ASCII]`, chunked like every Claude message.
- Pixel cat: original pixel-art frames generated by `tools/gen_cat.py` (no third-party art, Python 3 standard library only), stored as LVGL RGB565 images, animated only while the lock face is visible.
- Battery is 550 mAh: lock = panel off; the cat timer is paused whenever the face is hidden; BOOT is read by interrupt; no new periodic timers or tasks that wake on their own (the 250 ms screen timer and the 100 ms PMU poll already exist).
- Deep sleep rules unchanged (battery only, no link for 3 min; touch or BOOT wakes).
- Session picker contents are Phase 2: PWR ×3 shows a placeholder screen ("No sessions yet").
- LVGL threading: calls from non-LVGL tasks only between `bsp_display_lock((uint32_t)-1)` and `bsp_display_unlock()`; never take that lock inside LVGL event callbacks or `lv_timer` callbacks (they already run with it held). LVGL callbacks report inputs with `shell_post()` only.
- Board UI text is English and uses only `font_vi_22` / `font_vi_36` (ASCII + Vietnamese + `·` `…`; no emoji, no `×`).
- No `sdkconfig.defaults` changes are needed (`CONFIG_LV_USE_IMAGE`, `CONFIG_LV_DRAW_SW_COMPLEX` and RGB565 are already on).
- Commands: host tests `cd firmware/test && cc -Wall -Werror -I../main -o /tmp/<name> <name>.c ../main/<module>.c && /tmp/<name>`; firmware `. ~/esp/esp-idf/export.sh && cd firmware && idf.py build` (flash: `idf.py -p /dev/cu.usbmodem1101 flash monitor`); Mac `cd mac && swift test`; iOS `xcodebuild -project ios/ESPTranslator.xcodeproj -target ESPTranslator -sdk iphoneos CODE_SIGNING_ALLOWED=NO -quiet build`.

## Review Focus

1. **Double tap on the dark lock screen**: LVGL sends `SINGLE_CLICKED` and then `DOUBLE_CLICKED` for one double tap, so the face flashes and the board must end up unlocked, not stuck on the face (Task 1 test `double_tap_on_lock_screen_unlocks`; Task 7 on-device check).
2. **Claude request while locked that the user ignores or answers**: the panel lights with the request, lock gestures are not live over it, and once it is answered, cancelled or the Mac drops, the board is dark and still locked (Task 1 tests `urgent_while_locked_wakes_then_relocks`, `unlocking_over_a_request_keeps_it_shown`; Task 7 on-device check).
3. **Uneven PWR presses**: presses about 400–500 ms apart, more than three presses, a press that turns into a 3 s hold, timer wrap-around: never the wrong mode, never an accidental power-off (Task 1 tests `window_is_450_ms`, `counts_single_double_triple`, `hold_powers_off_once_and_eats_clicks`, `timer_wraparound`).
4. **Odd or bad time data**: garbage, trailing newline, overflow, a 2001 clock, half-hour and 45-minute zones, negative offsets that cross midnight, daylight saving: rejected or formatted right, `--:--` until a valid time arrives (Task 2 tests `rejects_garbage`, `formats_local_time`; Task 3 test `timeSyncUsesTheZoneOffsetAtThatInstant`).
5. **Activity while locked**: subtitles, the "Claude finished" toast, speech on the board mic and BLE reconnects must not light a locked panel (Task 1 tests assert `MODES_PANEL_OFF` regardless of anything but the face and requests; Task 7 puts the lock policy before every activity rule in `screen_timer_cb` and checks it on the device).

  - `typedef enum { MODES_EV_PWR_1 = 0, MODES_EV_PWR_2, MODES_EV_PWR_3, MODES_EV_BOOT_1, MODES_EV_TAP_1, MODES_EV_TAP_2, MODES_EV_URGENT, MODES_EV_URGENT_DONE } modes_event_t;`
  - `typedef enum { MODES_PANEL_AUTO = 0, MODES_PANEL_ON, MODES_PANEL_OFF } modes_panel_t;`

  - `bool modes_handle(modes_t *m, modes_event_t ev, int64_t now_us);` (true = wake the panel)
  - `board_screen_t modes_screen(const modes_t *m);`
  - `modes_panel_t modes_panel(const modes_t *m, int64_t now_us);`
  - `bool modes_face_visible(const modes_t *m, int64_t now_us);`
  - `typedef struct { bool down; bool hold_fired; uint32_t down_at_ms; uint32_t last_release_ms; int pending; } modes_clicks_t;`
  - `int modes_clicks_step(modes_clicks_t *c, bool pressed, bool released, uint32_t now_ms);` (0, 1..3, or `MODES_CLICKS_HOLD` = -1)
  - Constants: `MODES_FACE_US` (5 s), `MODES_CLICK_WINDOW_MS` (450), `MODES_HOLD_MS` (3000)

Behaviour decisions this task pins (they resolve spec gaps; see the tests):
- PWR ×2 when already in Claude mode stays in Claude mode (the spec says "Claude mode", not "toggle"); BOOT ×1 is the way back to the translator.
- A Claude request (`MODES_EV_URGENT`) shows the Claude screen over any mode and over the lock (still locked). When it is done (`MODES_EV_URGENT_DONE`) the screen goes back to the mode, or to the dark lock screen.
- PWR ×1 while a request is shown *unlocked* locks the board and hides the request (it stays pending and answerable in Claude mode). PWR ×1 while a request is shown *over the lock* unlocks and keeps the request on screen. PWR ×2/×3 and BOOT ×1 are explicit choices and end the takeover.
- Lock-screen taps are ignored while a request is shown over the lock (the lock screen is not visible then).
- Unlocked taps are not mode inputs: the translator keeps its own double-tap screen-off handler in `ui.c`; on the Claude and picker screens a double tap does nothing.

```c
// firmware/test/test_modes.c — build: cc -Wall -Werror -I../main -o /tmp/test_modes test_modes.c ../main/modes.c && /tmp/test_modes
#include <assert.h>
#include <stdio.h>
#include "modes.h"

#define SEC 1000000LL

static modes_t fresh(void)
{
    modes_t m;
    modes_init(&m);
    return m;
}

static void starts_unlocked_in_translator(void)
{
    modes_t m = fresh();
    assert(m.mode == BOARD_TRANSLATOR && !m.locked && !m.urgent);
    assert(modes_screen(&m) == SCREEN_TRANSLATOR);
    assert(modes_panel(&m, 0) == MODES_PANEL_AUTO);
}

static void pwr1_locks_and_unlocks_to_previous_mode(void)
{
    modes_t m = fresh();
    assert(modes_handle(&m, MODES_EV_PWR_2, 0));          /* Claude mode, wakes */
    assert(!modes_handle(&m, MODES_EV_PWR_1, 0));         /* lock: no wake */
    assert(m.locked && modes_screen(&m) == SCREEN_LOCK);
    assert(modes_panel(&m, 1 * SEC) == MODES_PANEL_OFF);
    assert(modes_handle(&m, MODES_EV_PWR_1, 2 * SEC));    /* unlock wakes */
    assert(!m.locked && modes_screen(&m) == SCREEN_CLAUDE);
    assert(modes_panel(&m, 2 * SEC) == MODES_PANEL_AUTO);
}

static void mode_buttons_switch_when_unlocked(void)
{
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_PWR_2, 0);
    assert(modes_screen(&m) == SCREEN_CLAUDE);
    modes_handle(&m, MODES_EV_PWR_2, 0);                  /* already Claude: stays (not a toggle) */
    assert(modes_screen(&m) == SCREEN_CLAUDE);
    modes_handle(&m, MODES_EV_PWR_3, 0);
    assert(modes_screen(&m) == SCREEN_PICKER);
    assert(modes_handle(&m, MODES_EV_BOOT_1, 0));
    assert(modes_screen(&m) == SCREEN_TRANSLATOR);
}

static void mode_buttons_unlock_into_their_mode(void)
{
    const modes_event_t evs[] = { MODES_EV_PWR_2, MODES_EV_PWR_3, MODES_EV_BOOT_1 };
    const board_screen_t want[] = { SCREEN_CLAUDE, SCREEN_PICKER, SCREEN_TRANSLATOR };
    for (int i = 0; i < 3; i++) {
        modes_t m = fresh();
        modes_handle(&m, MODES_EV_PWR_3, 0);              /* in use before locking: picker */
        modes_handle(&m, MODES_EV_PWR_1, 0);
        assert(modes_handle(&m, evs[i], 0));
        assert(!m.locked && modes_screen(&m) == want[i]);
    }
}

static void tap_shows_lock_face_for_five_seconds(void)
{
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_PWR_1, 0);
    assert(!modes_face_visible(&m, 10 * SEC));
    assert(!modes_handle(&m, MODES_EV_TAP_1, 10 * SEC));   /* face is not a wake: the policy turns it on */
    assert(m.locked && modes_screen(&m) == SCREEN_LOCK);
    assert(modes_face_visible(&m, 10 * SEC));
    assert(modes_panel(&m, 14 * SEC + 999999) == MODES_PANEL_ON);
    assert(modes_panel(&m, 15 * SEC) == MODES_PANEL_OFF);
    assert(!modes_face_visible(&m, 15 * SEC));
    modes_handle(&m, MODES_EV_TAP_1, 20 * SEC);             /* another tap restarts it */
    assert(modes_panel(&m, 24 * SEC) == MODES_PANEL_ON);
}

static void double_tap_on_lock_screen_unlocks(void)
{
    /* LVGL sends SINGLE then DOUBLE for one double tap: the face flashes, then the board unlocks */
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_PWR_2, 0);
    modes_handle(&m, MODES_EV_PWR_1, 0);
    modes_handle(&m, MODES_EV_TAP_1, 1 * SEC);
    assert(modes_handle(&m, MODES_EV_TAP_2, 1 * SEC));
    assert(!m.locked && modes_screen(&m) == SCREEN_CLAUDE);
    assert(!modes_face_visible(&m, 1 * SEC));
    modes_handle(&m, MODES_EV_PWR_1, 2 * SEC);              /* lock again: the old face timer is gone */
    assert(modes_panel(&m, 2 * SEC) == MODES_PANEL_OFF);
}

static void taps_do_nothing_when_unlocked(void)
{
    modes_t m = fresh();
    assert(!modes_handle(&m, MODES_EV_TAP_1, 0));
    assert(!modes_handle(&m, MODES_EV_TAP_2, 0));
    assert(!m.locked && modes_screen(&m) == SCREEN_TRANSLATOR && m.face_until_us == 0);
}

static void urgent_takes_over_then_returns(void)
{
    modes_t m = fresh();
    assert(modes_handle(&m, MODES_EV_URGENT, 0));
    assert(modes_screen(&m) == SCREEN_CLAUDE);
    assert(!modes_handle(&m, MODES_EV_URGENT_DONE, 0));
    assert(modes_screen(&m) == SCREEN_TRANSLATOR);
}

static void urgent_while_locked_wakes_then_relocks(void)
{
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_PWR_1, 0);
    assert(modes_handle(&m, MODES_EV_URGENT, 1 * SEC));
    assert(m.locked && modes_screen(&m) == SCREEN_CLAUDE);
    assert(modes_panel(&m, 60 * SEC) == MODES_PANEL_ON);     /* stays lit while the request is shown */
    modes_handle(&m, MODES_EV_TAP_2, 2 * SEC);               /* lock gestures are not live over a request */
    assert(m.locked);
    modes_handle(&m, MODES_EV_URGENT_DONE, 61 * SEC);
    assert(m.locked && modes_screen(&m) == SCREEN_LOCK);
    assert(modes_panel(&m, 61 * SEC) == MODES_PANEL_OFF);
}

static void unlocking_over_a_request_keeps_it_shown(void)
{
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_PWR_1, 0);
    modes_handle(&m, MODES_EV_URGENT, 0);
    assert(modes_handle(&m, MODES_EV_PWR_1, 0));             /* unlock: request still on screen */
    assert(!m.locked && modes_screen(&m) == SCREEN_CLAUDE);
    modes_handle(&m, MODES_EV_URGENT_DONE, 0);
    assert(modes_screen(&m) == SCREEN_TRANSLATOR);           /* back to the mode in use before locking */
}

static void explicit_choices_end_the_takeover(void)
{
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_URGENT, 0);
    modes_handle(&m, MODES_EV_BOOT_1, 0);                    /* user picked the translator */
    assert(!m.urgent && modes_screen(&m) == SCREEN_TRANSLATOR);

    modes_handle(&m, MODES_EV_URGENT, 0);
    modes_handle(&m, MODES_EV_PWR_1, 0);                     /* user locked the board */
    assert(m.locked && !m.urgent && modes_screen(&m) == SCREEN_LOCK);
    assert(modes_panel(&m, 0) == MODES_PANEL_OFF);
}

static void urgent_done_without_takeover_is_harmless(void)
{
    modes_t m = fresh();
    modes_handle(&m, MODES_EV_PWR_3, 0);
    modes_handle(&m, MODES_EV_URGENT_DONE, 0);
    assert(modes_screen(&m) == SCREEN_PICKER && !m.locked);
}

/* Feeds a press/release script: each entry is one 100 ms poll. Returns the first non-zero result. */
static int run_clicks(modes_clicks_t *c, const char *polls, uint32_t *t)
{
    for (const char *p = polls; *p; p++, *t += 100) {
        int r = modes_clicks_step(c, *p == 'P' || *p == 'B', *p == 'R' || *p == 'B', *t);
        if (r) {
            return r;
        }
    }
    return 0;
}

static void counts_single_double_triple(void)
{
    /* P = pressed, R = released, B = both in one poll, . = nothing */
    modes_clicks_t c = { 0 };
    uint32_t t = 1000;
    assert(run_clicks(&c, "PR.....", &t) == 1);
    c = (modes_clicks_t){ 0 };
    assert(run_clicks(&c, "PR..PR.....", &t) == 2);
    c = (modes_clicks_t){ 0 };
    assert(run_clicks(&c, "BB.B.....", &t) == 3);
    c = (modes_clicks_t){ 0 };
    assert(run_clicks(&c, "BBBBB.....", &t) == 3);             /* 5 quick presses still mean x3 */
}

static void window_is_450_ms(void)
{
    modes_clicks_t c = { 0 };
    uint32_t t = 0;
    assert(run_clicks(&c, "PR....PR.....", &t) == 2);        /* 400 ms gap: same series */
    c = (modes_clicks_t){ 0 };
    assert(run_clicks(&c, "PR.....", &t) == 1);              /* 500 ms of quiet ends a series */
    assert(c.pending == 0);
    assert(run_clicks(&c, "PR.....", &t) == 1);              /* the next press starts a new one */
}

static void hold_powers_off_once_and_eats_clicks(void)
{
    modes_clicks_t c = { 0 };
    uint32_t t = 0;
    /* a click, then press and hold: the hold wins and the earlier click is dropped */
    assert(run_clicks(&c, "B.P................................", &t) == MODES_CLICKS_HOLD);
    assert(run_clicks(&c, "......R......", &t) == 0);        /* release after the hold: no click */
    assert(c.pending == 0);
}

static void timer_wraparound(void)
{
    modes_clicks_t c = { 0 };
    uint32_t t = 0xFFFFFF00u;
    assert(run_clicks(&c, "PR.....", &t) == 1);
}
```

```c
/*
 * Board shell state machine (pure C, host-tested in firmware/test/test_modes.c).
 * Owns which mode is in use, the lock, the lock face timer and Claude "urgent" takeovers.
 * No ESP-IDF or LVGL here: shell.c feeds it events and applies the result.
 */
#pragma once
#include <stdbool.h>
#include <stdint.h>

typedef enum { BOARD_TRANSLATOR = 0, BOARD_CLAUDE, BOARD_PICKER } board_mode_t;
typedef enum { SCREEN_TRANSLATOR = 0, SCREEN_CLAUDE, SCREEN_PICKER, SCREEN_LOCK } board_screen_t;

typedef enum {
    MODES_EV_PWR_1 = 0,
    MODES_EV_PWR_2,
    MODES_EV_PWR_3,
    MODES_EV_BOOT_1,
    MODES_EV_TAP_1,        /* single tap on the lock screen */
    MODES_EV_TAP_2,        /* double tap on the lock screen */
    MODES_EV_URGENT,       /* a Claude request needs the user: show it, wake the panel */
    MODES_EV_URGENT_DONE,  /* that request was answered, cancelled or dropped */
} modes_event_t;

/* Panel power policy: AUTO = the usual idle timer / manual screen-off decide */
typedef enum { MODES_PANEL_AUTO = 0, MODES_PANEL_ON, MODES_PANEL_OFF } modes_panel_t;

#define MODES_FACE_US (5LL * 1000 * 1000)   /* lock face stays up this long after a tap */

typedef struct {
    board_mode_t mode;       /* mode in use; shown when unlocked, restored on unlock */
    bool locked;
    bool urgent;             /* a Claude request is shown over the mode (or over the lock) */
    int64_t face_until_us;   /* lock face visible until this time; 0 = hidden */
} modes_t;

void modes_init(modes_t *m);
/* Applies one input. Returns true when the panel must wake now (clear manual screen-off, mark activity). */
bool modes_handle(modes_t *m, modes_event_t ev, int64_t now_us);
board_screen_t modes_screen(const modes_t *m);
modes_panel_t modes_panel(const modes_t *m, int64_t now_us);
bool modes_face_visible(const modes_t *m, int64_t now_us);

/* PWR button press counting, fed from the PMU interrupt poll (pmu.c, every 100 ms). */
#define MODES_CLICK_WINDOW_MS 450    /* a press ends a series once this long passes after its release */
#define MODES_HOLD_MS         3000
#define MODES_CLICKS_HOLD     (-1)

typedef struct {
    bool down;
    bool hold_fired;
    uint32_t down_at_ms;
    uint32_t last_release_ms;
    int pending;
} modes_clicks_t;

/* pressed / released: the PMU key events seen in this poll (both may be set). Returns 0 (nothing yet),
 * 1..3 (a finished series; 4+ presses count as 3) or MODES_CLICKS_HOLD (held MODES_HOLD_MS, fired once). */
int modes_clicks_step(modes_clicks_t *c, bool pressed, bool released, uint32_t now_ms);
```

```c
static bool unlock_to(modes_t *m, board_mode_t mode)
{
    m->mode = mode;
    m->locked = false;
    m->urgent = false;
    m->face_until_us = 0;
    return true;
}

bool modes_handle(modes_t *m, modes_event_t ev, int64_t now_us)
{
    switch (ev) {
    case MODES_EV_PWR_1:
        if (m->locked) {
            /* Back to the mode in use; a request shown over the lock stays up until it is done */
            m->locked = false;
            m->face_until_us = 0;
            return true;
        }
        m->locked = true;
        m->urgent = false;   /* the user put the board away: a shown request goes dark (it stays pending) */
        m->face_until_us = 0;
        return false;
    case MODES_EV_PWR_2:
        return unlock_to(m, BOARD_CLAUDE);
    case MODES_EV_PWR_3:
        return unlock_to(m, BOARD_PICKER);
    case MODES_EV_BOOT_1:
        return unlock_to(m, BOARD_TRANSLATOR);
    case MODES_EV_TAP_1:
        if (m->locked && !m->urgent) {
            m->face_until_us = now_us + MODES_FACE_US;
        }
        return false;
    case MODES_EV_TAP_2:
        if (m->locked && !m->urgent) {
            m->locked = false;
            m->face_until_us = 0;
            return true;
        }
        return false;
    case MODES_EV_URGENT:
        m->urgent = true;
        m->face_until_us = 0;
        return true;
    case MODES_EV_URGENT_DONE:
        m->urgent = false;
        return false;
    }
    return false;
}

board_screen_t modes_screen(const modes_t *m)
{
    if (m->urgent) {
        return SCREEN_CLAUDE;
    }
    if (m->locked) {
        return SCREEN_LOCK;
    }
    switch (m->mode) {
    case BOARD_CLAUDE:
        return SCREEN_CLAUDE;
    case BOARD_PICKER:
        return SCREEN_PICKER;
    default:
        return SCREEN_TRANSLATOR;
    }
}

bool modes_face_visible(const modes_t *m, int64_t now_us)
{
    return m->locked && !m->urgent && now_us < m->face_until_us;
}

modes_panel_t modes_panel(const modes_t *m, int64_t now_us)
{
    if (!m->locked) {
        return MODES_PANEL_AUTO;
    }
    if (m->urgent || modes_face_visible(m, now_us)) {
        return MODES_PANEL_ON;
    }
    return MODES_PANEL_OFF;
}

int modes_clicks_step(modes_clicks_t *c, bool pressed, bool released, uint32_t now_ms)
{
    if (pressed) {
        c->down = true;
        c->hold_fired = false;
        c->down_at_ms = now_ms;
    }
    if (released) {
        if (c->down && !c->hold_fired) {
            c->pending++;
            c->last_release_ms = now_ms;
        }
        c->down = false;
    }
    if (c->down && !c->hold_fired && now_ms - c->down_at_ms >= MODES_HOLD_MS) {
        c->hold_fired = true;
        c->pending = 0;
        return MODES_CLICKS_HOLD;
    }
    if (c->pending > 0 && !c->down && now_ms - c->last_release_ms >= MODES_CLICK_WINDOW_MS) {
        int n = c->pending > 3 ? 3 : c->pending;
        c->pending = 0;
        return n;
    }
    return 0;
}
```

```c
#include "clock.h"

#include <stdlib.h>

#define CLOCK_MIN_UNIX 1700000000LL   /* 2023-11-14 */
#define CLOCK_MAX_UNIX 4102444800LL   /* 2100-01-01 */
#define CLOCK_MIN_OFFSET (-12 * 60)
#define CLOCK_MAX_OFFSET (14 * 60)

static bool parse_int(const char **p, bool allow_sign, long long *out)
{
    const char *s = *p;
    bool neg = false;
    if (allow_sign && (*s == '-' || *s == '+')) {
        neg = *s == '-';
        s++;
    }
    if (*s < '0' || *s > '9') {
        return false;
    }
    long long v = 0;
    int digits = 0;
    while (*s >= '0' && *s <= '9') {
        if (++digits > 12) {
            return false;
        }
        v = v * 10 + (*s - '0');
        s++;
    }
    *out = neg ? -v : v;
    *p = s;
    return true;
}

bool clock_parse(const char *text, clock_sync_t *out)
{
    if (!text) {
        return false;
    }
    const char *p = text;
    long long secs, offset;
    if (!parse_int(&p, false, &secs) || *p++ != ' ' || !parse_int(&p, true, &offset) || *p != '\0') {
        return false;
    }
    if (secs < CLOCK_MIN_UNIX || secs >= CLOCK_MAX_UNIX || offset < CLOCK_MIN_OFFSET || offset > CLOCK_MAX_OFFSET) {
        return false;
    }
    out->unix_s = secs;
    out->offset_min = (int)offset;
    return true;
}

void clock_format_hhmm(int64_t unix_s, int offset_min, char out[6])
{
    int64_t local = unix_s + (int64_t)offset_min * 60;
    int64_t sod = local % 86400;
    if (sod < 0) {
        sod += 86400;
    }
    int h = (int)(sod / 3600), m = (int)(sod % 3600 / 60);
    out[0] = (char)('0' + h / 10);
    out[1] = (char)('0' + h % 10);
    out[2] = ':';
    out[3] = (char)('0' + m / 10);
    out[4] = (char)('0' + m % 10);
    out[5] = '\0';
}
```

```c
/* Device side of clock.h: system time via settimeofday (kept by the RTC timer, also across deep sleep). */
#include <string.h>
#include <sys/time.h>

#include "esp_attr.h"
#include "esp_log.h"

#include "clock.h"

static const char *TAG = "clock";

/* RTC memory: survives deep sleep (like the system time), cleared when the board loses power */
RTC_DATA_ATTR static bool s_known;
RTC_DATA_ATTR static int16_t s_offset_min;

bool clock_sync_text(const char *text)
{
    clock_sync_t s;
    if (!clock_parse(text, &s)) {
        ESP_LOGW(TAG, "ignoring bad time \"%.24s\"", text ? text : "");
        return false;
    }
    struct timeval tv = { .tv_sec = (time_t)s.unix_s, .tv_usec = 0 };
    settimeofday(&tv, NULL);
    s_offset_min = (int16_t)s.offset_min;
    s_known = true;
    ESP_LOGI(TAG, "time set: %lld, UTC offset %+d min", (long long)s.unix_s, s.offset_min);
    return true;
}

bool clock_now_hhmm(char out[6])
{
    if (!s_known) {
        memcpy(out, "--:--", 6);
        return false;
    }
    struct timeval tv;
    gettimeofday(&tv, NULL);
    clock_format_hhmm((int64_t)tv.tv_sec, s_offset_min, out);
    return true;
}
```

```python
#!/usr/bin/env python3
"""Generates the lock-face pixel cat (original art) as LVGL RGB565 images.

The cat is drawn here as a 32x32 character grid, upscaled x3 to 96x96 pixels, and written as
firmware/main/cat_frames.c. The board shows it at x2 (192x192) with antialiasing off.
Plain Python 3, no dependencies. Run from the repo root:  python3 tools/gen_cat.py
"""
import os
import sys

SIZE = 32          # logical grid
UPSCALE = 3        # 32 * 3 = 96 px per side in flash
OUT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "firmware", "main", "cat_frames.c")

PALETTE = {
    ".": (0x00, 0x00, 0x00),   # background: the lock face is black
    "L": (0x6b, 0x3a, 0x14),   # outline, dark brown (visible on black)
    "O": (0xf0, 0xa0, 0x40),   # orange fur
    "D": (0xc0, 0x6a, 0x20),   # tabby stripes
    "W": (0xf4, 0xee, 0xe0),   # muzzle, chest, paws
    "N": (0xf0, 0x88, 0x90),   # nose, inner ears
    "E": (0x8c, 0xe0, 0x6a),   # eyes
    "P": (0x18, 0x18, 0x18),   # pupils, mouth
}

# Sitting cat, front view; tail drawn separately. Columns 0..31.
BODY = [
    "................................",  # 0
    "................................",  # 1
    "....L..............L............",  # 2
    "....LL............LL............",  # 3
    "....LOL..........LOL............",  # 4
    "....LNOL........LONL............",  # 5
    "....LNOOLLLLLLLLOONL............",  # 6
    "....LOOOODDODDOOOOOL............",  # 7
    "...LOOOOOODDDDOOOOOOL...........",  # 8 (head widens by one on each side)
    "...LOOOOOOOOOOOOOOOOL...........",  # 9
    "...LOOEEEOOOOOOEEEOOL...........",  # 10 eyes
    "...LOOEPEOOOOOOEPEOOL...........",  # 11
    "...LDOOOOOOWWOOOOOODL...........",  # 12
    "...LOOOOOWWNNWWOOOOOL...........",  # 13 nose
    "....LOOOOWWPPWWOOOOL............",  # 14 mouth
    ".....LLOOOWWWWOOOLL.............",  # 15 chin
    "......LOOOOWWOOOOL..............",  # 16 neck
    ".....LOOOOWWWWOOOOL.............",  # 17
    ".....LODOOWWWWOODOL.............",  # 18
    "....LOODOOWWWWOODOOL............",  # 19
    "....LOOOOWWWWWWOOOOL............",  # 20
    "....LODOOWWWWWWOODOL............",  # 21
    "....LOODOWWWWWWODOOL............",  # 22
    "....LOOOOWWWWWWOOOOL............",  # 23
    "....LOODOOWWWWOODOOL............",  # 24
    "....LOOOOOWWWWOOOOOL............",  # 25
    "....LOOOOOOWWOOOOOOL............",  # 26
    "....LOOLWWLOOLWWLOOL............",  # 27 front paws
    "....LOOLWWWLLWWWLOOL............",  # 28
    ".....LLLLLLLLLLLLLL.............",  # 29
    "................................",  # 30
    "................................",  # 31
]

# Tail positions: (row, col) cells painted "O" with a "D" tip (last cell).
TAILS = {
    "down": [(28, 20), (28, 21), (28, 22), (28, 23), (27, 24), (27, 25), (26, 26), (25, 26)],
    "mid":  [(28, 20), (28, 21), (27, 22), (26, 23), (25, 23), (24, 24), (23, 24), (22, 24)],
    "up":   [(28, 20), (27, 21), (26, 22), (25, 22), (24, 22), (23, 22), (22, 23), (21, 24), (20, 24)],
}

EYES_CLOSED = {(10, 6): "O", (10, 7): "O", (10, 8): "O", (11, 6): "P", (11, 7): "P", (11, 8): "P",
               (10, 15): "O", (10, 16): "O", (10, 17): "O", (11, 15): "P", (11, 16): "P", (11, 17): "P"}

# Unique images, then the order the board plays them (one step every CAT_FRAME_MS on the board)
FRAMES = [("down", False), ("mid", False), ("up", False), ("down", True)]
SEQUENCE = [0, 0, 1, 2, 1, 0, 0, 3, 0, 0, 1, 2, 2, 1]


def grid(tail, blink):
    g = [list(row) for row in BODY]
    cells = TAILS[tail]
    for i, (r, c) in enumerate(cells):
        g[r][c] = "D" if i == len(cells) - 1 else "O"
        g[r + 1][c] = "O" if g[r + 1][c] == "." else g[r + 1][c]   # two cells thick
    if blink:
        for (r, c), ch in EYES_CLOSED.items():
            g[r][c] = ch
    return g


def rgb565_le(rgb):
    r, gr, b = rgb
    v = ((r >> 3) << 11) | ((gr >> 2) << 5) | (b >> 3)
    return (v & 0xFF, v >> 8)


def frame_bytes(g):
    out = bytearray()
    for row in g:
        line = bytearray()
        for ch in row:
            lo, hi = rgb565_le(PALETTE[ch])
            line += bytes((lo, hi)) * UPSCALE
        out += bytes(line) * UPSCALE
    return out


def check():
    for i, row in enumerate(BODY):
        if len(row) != SIZE:
            sys.exit(f"BODY row {i} has {len(row)} columns, expected {SIZE}")
        bad = set(row) - set(PALETTE)
        if bad:
            sys.exit(f"BODY row {i} uses unknown colours {bad}")
    if len(BODY) != SIZE:
        sys.exit(f"BODY has {len(BODY)} rows, expected {SIZE}")
    for name, cells in TAILS.items():
        for r, c in cells:
            if not (0 <= r < SIZE - 1 and 0 <= c < SIZE):
                sys.exit(f"tail {name} cell {(r, c)} is off the grid")
    if any(i >= len(FRAMES) for i in SEQUENCE):
        sys.exit("SEQUENCE refers to a missing frame")


def main():
    check()
    px = SIZE * UPSCALE
    parts = [
        "/* Generated by tools/gen_cat.py: original pixel art. Do not edit; edit the script and re-run it. */\n",
        '#include "cat_frames.h"\n\n',
    ]
    for n, (tail, blink) in enumerate(FRAMES):
        data = frame_bytes(grid(tail, blink))
        assert len(data) == px * px * 2
        parts.append(f"static const uint8_t frame{n}_map[{len(data)}] = {{\n")
        for off in range(0, len(data), 24):
            parts.append("    " + ", ".join(f"0x{b:02x}" for b in data[off:off + 24]) + ",\n")
        parts.append("};\n\n")
        parts.append(
            f"static const lv_image_dsc_t frame{n} = {{\n"
            f"    .header.magic = LV_IMAGE_HEADER_MAGIC,\n"
            f"    .header.cf = LV_COLOR_FORMAT_RGB565,\n"
            f"    .header.w = {px},\n"
            f"    .header.h = {px},\n"
            f"    .header.stride = {px * 2},\n"
            f"    .data_size = sizeof(frame{n}_map),\n"
            f"    .data = frame{n}_map,\n"
            f"}};\n\n")
    parts.append("const lv_image_dsc_t *const cat_frames[] = { "
                 + ", ".join(f"&frame{n}" for n in range(len(FRAMES))) + " };\n")
    parts.append(f"const int cat_frame_count = {len(FRAMES)};\n")
    parts.append("const uint8_t cat_sequence[] = { " + ", ".join(str(i) for i in SEQUENCE) + " };\n")
    parts.append(f"const int cat_sequence_len = {len(SEQUENCE)};\n")
    with open(OUT, "w") as f:
        f.write("".join(parts))
    print(f"wrote {os.path.normpath(OUT)}: {len(FRAMES)} frames of {px}x{px} RGB565, "
          f"{len(FRAMES) * px * px * 2} bytes of pixels")
    if "--preview" in sys.argv:
        for tail, blink in FRAMES:
            print(f"--- tail {tail}, blink {blink}")
            print("\n".join("".join(r) for r in grid(tail, blink)))


if __name__ == "__main__":
    main()
```

Create `firmware/main/shell.c`:

```c
/*
 * Board shell: turns button and gesture inputs into mode changes (modes.c) and applies them: which screen
 * is loaded and whether the panel must wake. The panel power policy itself is read by ui.c's screen timer
 * (shell_snapshot + modes_panel).
 * Inputs: PWR x1/x2/x3 from pmu.c, BOOT (GPIO0, active low) by interrupt here, lock-screen taps from
 * lock_ui.c, Claude requests from main.c / claude_ui.c. shell_post() never blocks and is safe from any task,
 * LVGL callbacks and timers included; only the shell task touches the display lock.
 */
#include "bsp/esp-bsp.h"
#include "driver/gpio.h"
#include "esp_attr.h"
#include "esp_log.h"
#include "esp_timer.h"
#include "freertos/FreeRTOS.h"
#include "freertos/queue.h"
#include "freertos/task.h"

#include "app.h"

static const char *TAG = "shell";

#define BOOT_GPIO        GPIO_NUM_0
#define BOOT_DEBOUNCE_US (250 * 1000)   /* contact bounce; a repeated BOOT x1 is harmless anyway */

static QueueHandle_t s_queue;
static modes_t s_state;
static portMUX_TYPE s_mux = portMUX_INITIALIZER_UNLOCKED;

static const char *const EV_NAMES[] = {
    "PWR x1", "PWR x2", "PWR x3", "BOOT x1", "tap x1", "tap x2", "Claude request", "Claude request done",
};

void shell_post(modes_event_t ev)
{
    if (s_queue) {
        xQueueSend(s_queue, &ev, 0);
    }
}

void shell_snapshot(modes_t *out)
{
    taskENTER_CRITICAL(&s_mux);
    *out = s_state;
    taskEXIT_CRITICAL(&s_mux);
}

static void IRAM_ATTR boot_isr(void *arg)
{
    static int64_t last_us;
    int64_t now = esp_timer_get_time();
    if (now - last_us < BOOT_DEBOUNCE_US) {
        return;
    }
    last_us = now;
    modes_event_t ev = MODES_EV_BOOT_1;
    BaseType_t woken = pdFALSE;
    xQueueSendFromISR(s_queue, &ev, &woken);
    if (woken) {
        portYIELD_FROM_ISR();
    }
}

static lv_obj_t *screen_obj(board_screen_t s)
{
    switch (s) {
    case SCREEN_CLAUDE:
        return claude_ui_screen();
    case SCREEN_PICKER:
        return picker_ui_screen();
    case SCREEN_LOCK:
        return lock_ui_screen();
    default:
        return ui_translator_screen();
    }
}

static void shell_task(void *arg)
{
    modes_event_t ev;
    while (xQueueReceive(s_queue, &ev, portMAX_DELAY) == pdTRUE) {
        int64_t now = esp_timer_get_time();
        modes_t next;
        taskENTER_CRITICAL(&s_mux);
        bool wake = modes_handle(&s_state, ev, now);
        next = s_state;
        taskEXIT_CRITICAL(&s_mux);

        ESP_LOGI(TAG, "%s -> mode %d%s%s", EV_NAMES[ev], (int)next.mode, next.locked ? ", locked" : "",
                 next.urgent ? ", request shown" : "");
        if (wake) {
            ui_force_screen_on();
        }
        lv_obj_t *target = screen_obj(modes_screen(&next));
        bsp_display_lock((uint32_t)-1);
        if (lv_screen_active() != target) {
            lv_screen_load(target);
        }
        bsp_display_unlock();
    }
}

void shell_start(void)
{
    modes_init(&s_state);
    s_queue = xQueueCreate(16, sizeof(modes_event_t));
    xTaskCreate(shell_task, "shell", 3072, NULL, 5, NULL);

    gpio_config_t io = {
        .pin_bit_mask = 1ULL << BOOT_GPIO,
        .mode = GPIO_MODE_INPUT,
        .pull_up_en = GPIO_PULLUP_ENABLE,
        .intr_type = GPIO_INTR_NEGEDGE,
    };
    ESP_ERROR_CHECK(gpio_config(&io));
    esp_err_t err = gpio_install_isr_service(0);   /* the touch driver may have installed it already */
    if (err != ESP_OK && err != ESP_ERR_INVALID_STATE) {
        ESP_LOGW(TAG, "BOOT button unavailable: %s", esp_err_to_name(err));
        return;
    }
    ESP_ERROR_CHECK(gpio_isr_handler_add(BOOT_GPIO, boot_isr, NULL));
}
```
